TableSweep

A fast Chrome extension that extracts tables, data grids, and repeating lists from any webpage into clean CSV, Excel (.xlsx), JSON, or Markdown files.

Chrome Extension - Local and Private

Works on Modern Sites

Captures classic HTML tables, ARIA/React data grids, and repeating card lists using the built-in visual picker.

Excel-Safe Exports

Includes UTF-8 BOM for international characters, preserves leading zeros and long numeric IDs, and aligns merged cells.

Private by Design

All table parsing and file generation runs locally in your browser. Webpage contents are never sent to external servers.

  • CSV, TSV, clipboard copy, column selector, and visual picker
